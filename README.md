# Food Delivery Data Analysis 📊

## Project Overview
This project analyzes food delivery data by combining transactional,
user, and restaurant datasets to derive business insights.

## Datasets Used
- orders.csv (Transactional data)
- users.json (User master data)
- restaurants.sql (Restaurant master data)

## Steps Performed
1. Loaded CSV, JSON, and SQL datasets
2. Performed LEFT JOINs to combine all data
3. Created a final consolidated dataset
4. Analyzed revenue, user behavior, cuisine trends, and membership impact

## Tools & Technologies
- Python
- Pandas
- SQLite
- Jupyter Notebook

## Output
- final_food_delivery_dataset.csv

## Key Insights
- Gold members contribute significantly to revenue
- Certain cuisines have higher average order values
- High-rated restaurants generate more revenue
